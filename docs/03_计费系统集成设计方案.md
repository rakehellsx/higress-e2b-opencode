# 类 Manus 智能体平台：计费系统集成与计量方案设计

## 1. 引言

在构建基于 Higress、OpenCode 和 E2B 的大模型网关与类 Manus 智能体平台时，实现精确的按需计费（Usage-based Billing）是平台商业化运营的核心。传统的基于固定订阅的计费模式无法准确反映大模型调用和沙箱计算资源的实际消耗。本文档详细设计了如何将计费系统无缝集成到现有多租户架构中，涵盖计量数据采集、计费模型设计以及账单与支付集成。

## 2. 计费系统架构全景

为了支持高吞吐量的 LLM API 调用和实时的沙箱资源消耗，我们采用“事件驱动的实时计量与异步计费”架构。该架构解耦了“计量（Metering）”和“计费（Billing）”两个过程，确保核心业务路径的低延迟。

| 架构组件 | 核心职责 | 关键技术与工具 |
| :--- | :--- | :--- |
| **数据采集层** | 拦截 LLM 请求与沙箱生命周期事件，生成标准化计量事件。 | Higress `ai-statistics` 插件、E2B Lifecycle Webhooks。 |
| **事件流处理层** | 高吞吐量接收计量事件，进行缓冲、去重与初步聚合。 | Apache Kafka / Redis Stream。 |
| **实时计量引擎** | 聚合事件，维护租户实时余额，执行配额拦截。 | OpenMeter (基于 ClickHouse)。 |
| **计费与账单系统** | 根据定价策略计算最终费用，生成周期性账单并处理支付。 | Stripe Billing / 自研计费模块。 |

## 3. 核心机制详解

### 3.1 计量数据采集 (Data Ingestion)

精确的计费依赖于高质量、无遗漏的计量数据采集。在我们的平台中，主要存在两类资源消耗：

1.  **大模型 Token 消耗**：由 Higress AI 网关负责采集。通过启用 Higress 的 `ai-statistics` 插件，网关能够解析 OpenAI 协议或自定义协议的响应体，提取 `input_token` 和 `output_token`。我们将配置网关，将这些指标与租户 ID（通过 `request_header` 提取的 `consumer` 字段）打包为标准的 CloudEvents 格式，异步发送至 Kafka 消息队列。
2.  **沙箱计算资源消耗**：由 E2B 平台负责采集。利用 E2B 的 Lifecycle Events Webhooks，平台可以实时监听沙箱的 `created`、`paused`、`resumed` 和 `killed` 事件。平台后端接收这些 Webhook 后，结合沙箱的配置规格（如 vCPU 和内存大小），计算实际运行时间（以秒为单位），并生成相应的计算资源计量事件。

### 3.2 实时计量引擎 (Real-time Metering)

为了处理海量的并发事件并支持实时余额查询，我们引入 OpenMeter（或类似的基于 ClickHouse 的实时计量引擎）。

*   **事件聚合**：OpenMeter 从 Kafka 消费标准化事件，利用 ClickHouse 的列式存储优势，进行实时的 SUM、COUNT 等聚合操作。
*   **多维度计量**：系统不仅记录总 Token 数，还支持按 `model`（如 gpt-4-turbo、claude-3-opus）和 `tenant_id` 进行多维度分组统计。这使得平台能够针对不同模型制定差异化的定价策略。
*   **配额联动**：实时计量结果通过 API 反馈给 Higress 网关的 `ai-quota` 和 `ai-token-ratelimit` 插件。当租户余额不足或达到速率限制时，网关可以在毫秒级拦截请求，防止资源超用。

### 3.3 计费模型与账单生成 (Billing & Invoicing)

计费系统（如 Stripe Billing）负责将技术指标转化为商业价值。

*   **混合计费模型**：平台采用“基础订阅费 + 阶梯式按量计费（Tiered Usage-based Pricing）”的混合模型。例如，基础版包含 100 万 Token 和 10 小时沙箱时间，超出部分按阶梯价格计费。
*   **预付费积分系统（Prepaid Credits）**：支持用户预先购买积分（Credits）。计量引擎实时扣减积分余额，当积分耗尽时，系统自动触发告警并暂停服务。
*   **账单同步**：在每个计费周期（如自然月）结束时，平台后端从 OpenMeter 提取最终的聚合使用量，并将其同步至 Stripe。Stripe 根据预设的价格表（Rate Cards）自动生成账单，并向客户发起扣款请求。

## 4. 结论

通过将 Higress 的网关层采集能力、E2B 的沙箱生命周期管理与 OpenMeter/Stripe 等专业计量计费组件相结合，我们构建了一套高性能、高可用且高度灵活的按需计费系统。该系统不仅确保了平台收入的准确性，还为客户提供了透明、实时的成本可视化体验，是支撑平台规模化发展的关键基础设施。
